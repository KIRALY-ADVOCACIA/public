# Deploy

## Opção recomendada: Cloudflare Pages ou Vercel

O projeto é estático. Basta publicar a pasta `KADV-MANUTENCAO`.

## GitHub Pages

Se o repositório usar GitHub Pages, configure a origem para a pasta deste projeto ou copie os arquivos para a raiz da branch de publicação.

## DNS

Não apontar `www.kiraly.adv.br` sem aprovação final.

Antes de trocar DNS:

- Validar desktop.
- Validar mobile.
- Validar contador.
- Validar links.
- Validar formulário.
- Validar LGPD/política de privacidade, se aplicável.
